# Marrowbone Island

Python-based text adventure game developed for the University of Washington Youth & Teen Programs.

Students build the same game over two weeks, gradually introducing new Python concepts while expanding and refactoring the code. Each lesson includes a starter file and a completed instructor version.

## Lessons

1. `Marrowbone-Island-001-hello-world.py`
   - Hello World, comments, and `print()`

2. `Marrowbone-Island-002-variables.py`
   - Variables, data types, user input, and f-strings

3. `Marrowbone-Island-003-control.py`
   - Conditionals, loops, lists, and importing libraries

4. `Marrowbone-Island-004-debug.py`
   - Algorithms and debugging

5. `Marrowbone-Island-005-functions.py`
   - Functions and code organization

6. `Marrowbone-Island-006-dictionaries.py`
   - Dictionaries and location lookup

7. `Marrowbone-Island-007-read-write.py`
   - Reading from and writing to text files

8. `Marrowbone-Island-008-logic-finish-the-game.py`
   - Logical operators, nested conditionals, and finishing the game

9. `Marrowbone-Island-009-basic-game.py`
   - Expanded game and review

10. `Marrowbone-Island-010-laundry-shrimp.py`
    - Final instructor demo and Easter egg

## Supporting Files

- `*-complete.py` — Completed instructor versions for each lesson
- `intro.txt` — Intro text used for the file reading lesson
- `notes.txt` — Stores text for lesson on read/write
- `teaching-files/` — Supplemental teaching materials
- `Class 7 text files/` — Sample text files for file I/O activities
