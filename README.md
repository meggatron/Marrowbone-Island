# Marrowbone Island

# 2026 version
Python-based text adventure game with iterative versions developed for teaching Python.

## Versions

1. `Marrowbone-Island-001.py` — pseudocode (planning only)
2. `Marrowbone-Island-002-variables.py` — variables, data types, input/output
3. `Marrowbone-Island-003-control.py` — while loops, lists, importing libraries
4. `Marrowbone-Island-004-debug.py` — algorithms & debugging
5. `bubble-sort-algorithm.py` — Bubble Sort with print tracing
6. `selection-sort-algorithm.py` — Selection Sort with print tracing
7. `Marrowbone-Island-005-functions.py` — functions
8. `Marrowbone-Island-006-dictionaries.py` — dictionaries
9. `Marrowbone-Island-007-read-write.py` — file reading & writing
10. `Marrowbone-Island-008-logic.py` — nested logic & logical operators
11. `Marrowbone-Island-009-basic-game.py` — expanded game
12. `Marrowbone-Island-010-laundry-shrimp.py` — complete instructor demo
